# Лабораторная работа 5 — Вариант 1

Оптимизация выпуска трёх изделий при ограниченных запасах материалов.

## Запуск в Windows

Дважды нажмите `run_lab5.bat`. Нужен установленный Python 3.9 или новее
с Tkinter и доступ в интернет при первой установке зависимостей.
Скрипт создаёт отдельную среду `.venv_lab5` в каталоге проекта.

Либо выполните в терминале:

```powershell
python -m pip install -r requirements_lab5.txt
python lab5_variant1.py
```

Только расчёт в консоли:

```powershell
python lab5_variant1.py --cli
python -m unittest test_lab5 -v
```

## Использование

Все нормы расхода, запасы и цены редактируются. Поддерживаются точка и запятая.
«Рассчитать» обновляет план, таблицу ресурсов, диаграмму и сценарии изменения запасов.
«Очистить» восстанавливает исходные данные варианта 1 и выполняет расчёт.
Изменение данных сбрасывает предыдущий результат; JSON можно сохранить после расчёта.
Минус и буквы блокируются. Пустое поле при расчёте вызывает предупреждение.

## Модель и ответ

Максимизируется стоимость выпуска в у. е., поскольку в варианте заданы цены,
а не удельная прибыль. Затраты на производство в условии отсутствуют.

```text
F = 3*x1 + 3*x2 + 4*x3 -> max
x1 + 2*x2 + x3 <= 420
2*x1 + x2 + 3*x3 <= 600
4*x1 + 2*x2 + x3 <= 900
x1, x2, x3 >= 0
```

Модель непрерывная. Используется `scipy.optimize.linprog(method="highs-ds")`,
двойственный симплекс-метод HiGHS. Знак целевой функции меняется для минимизации.
Теневые цены также меняют знак при переводе результата к задаче максимизации.

Один из оптимумов: (160, 100, 60), F = 1020. У всех материалов остаток равен нулю,
но теневая цена S3 равна нулю. У S1 и S2 она равна 1 у. е./кг.
Солвер может выбрать другой равноценный план — это корректно.

Все оптимальные планы:
`(260 - 5*t/3, 80 + t/3, t)`, `60 <= t <= 156`.
Например, (0, 132, 156) оставляет 480 кг S3 при той же стоимости 1020.

Для S1 и S2 увеличение запаса на 10% даёт стоимость 1062 и 1080 соответственно;
для S3 — 1020. Ресурсы меняются по одному. Это стоимость выпуска, а не чистая прибыль.
Доход от дополнительного материала нужно сравнивать с ценой его приобретения.

При неотрицательных A, b, c нулевой план всегда допустим. В этом классе задач
статус INFEASIBLE не возникает; обработчик статуса предусмотрен. Нулевой столбец
расходов при положительной цене изделия приводит к UNBOUNDED.
